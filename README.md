# ShayneStyles

Frontend: Vue 3 + Vite.

Backend: Express + MongoDB in `backend/`.

## Run Frontend

```bash
npm run dev
```

## Run Backend

1. Copy `backend/.env.example` to `backend/.env` and set `MONGODB_URI`.
2. Install backend dependencies:

```bash
cd backend
npm install
```

3. Start the API:

```bash
npm run dev
```

## Root Scripts

- `npm run backend:dev`
- `npm run backend:start`
